# InstaWay

Node.js + Express + PostgreSQL. الواجهة في `public/`.

## تشغيل محلي
1. `npm install`
2. `cp .env.example .env` واملا القيم (`JWT_SECRET` 32+ حرف عشوائي، `DATABASE_URL`، `WALLET_NUMBER`)
3. `npm run db:init`
4. `ADMIN_PASSWORD='باسورد-طويل-12+' npm run admin:create -- اسم_الأدمن`
5. `npm start` ثم افتح `/` و `/admin.html`

ضع ملف `style.css` الأصلي بتاعك جوه `public/` (مش موجود هنا لأنه ماتبعتش).

## لوحة الأدمن
`/admin.html`: مؤشرات (إيراد، حجوزات، إلغاء، إشغال، اكتمال، استردادات)، رسم الإيراد اليومي، أداء كل خط، وإدارة الرحلات وتأكيد الدفع. البيانات من `GET /api/admin/stats?days=7|30|90`. الإشغال بيتحسب للرحلات اللي اتحركت بس.

## الحماية
- أسعار وكراسي من السيرفر فقط، والرقم ما بيظهرش في كود الواجهة غير بعد إنشاء الحجز
- منع الحجز المزدوج: قفل صف الرحلة + فهرس فريد على (trip, seat)
- Idempotency-Key، مهلة دفع، Rate limiting، honeypot، حد أقصى للحجوزات المعلقة لكل رقم
- أدمن: bcrypt، قفل بعد 5 محاولات، JWT في كوكي HttpOnly + SameSite=Strict + CSRF header، audit log
- Helmet + CSP، التحقق بـ zod، أخطاء منظمة بدون تفاصيل داخلية

## المراكز والأسعار
أسيوط ↔ ديروط 40 جنيه، أسيوط ↔ القوصية 30 جنيه، أسيوط ↔ منفلوط 15 جنيه (للكرسي، في الاتجاهين). السعر الافتراضي بيتملّى تلقائيًا في لوحة الأدمن (`FARES` في `src/validate.js`) وتقدر تعدّله لكل رحلة. الراكب بيدفع دايمًا سعر الرحلة المخزّن في السيرفر.

## قواعد العمل
الرحلة بتتأكد لما كل الكراسي (14) تتدفع. لو لسه ما اكتملتش عند آخر ميعاد حجز (3 ساعات قبل التحرك) بتتلغى تلقائيًا والمدفوع بيتحول REFUND_DUE (الاسترداد يدوي من الأدمن).
لو رحلة مؤكدة وبقى ناقصها كرسيين مدفوعين أو أكتر (إلغاء راكبين)، بترجع OPEN (غير مؤكدة). إلغاء راكب واحد بس بيسيبها مؤكدة. لو رجعت OPEN بعد آخر ميعاد حجز، بتتلغى تلقائيًا في الدقيقة الجاية والمدفوع بيتحول استرداد.
